# Blend · Recorrido 3D

Recorrido en 3D del local de **Blend** ("Diferentes historias, misma vibra"), una experiencia social e intercultural en restobares de Lima.

- **Ver en línea:** https://ater1410.github.io/Arian.Z/blend/
- Desliza hacia abajo (o usa las flechas ← →) para que la cámara recorra el local. Tecla **F** para pantalla completa.
- `index.html` funciona también sin internet: descárgalo y ábrelo con doble clic.
- `blend-bar.blend` es el modelo editable en Blender; `blend-bar.glb` es la exportación del mismo modelo.
